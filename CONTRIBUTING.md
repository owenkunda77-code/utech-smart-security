# Contributing to UTECH Smart Security

## Code of Conduct

Be respectful and constructive in all interactions.

## Getting Started

1. Fork the repository
2. Clone your fork
3. Create a feature branch
4. Follow the setup guide in SETUP.md

## Development Standards

### Code Style

- **Backend (TypeScript)**: Use ESLint configuration
- **Frontend (React)**: Follow React best practices
- **Mobile (React Native)**: Follow React Native guidelines

### Naming Conventions

- Files: `kebab-case.ts`
- Components: `PascalCase.tsx`
- Variables: `camelCase`
- Constants: `UPPER_SNAKE_CASE`

### Commit Messages

Follow conventional commits:
- `feat: add new feature`
- `fix: fix bug`
- `docs: update documentation`
- `refactor: refactor code`
- `test: add tests`

## Pull Request Process

1. Update tests if needed
2. Update documentation
3. Follow code style guidelines
4. Create PR with clear description
5. Ensure CI/CD passes
6. Request review from maintainers

## Reporting Issues

Include:
- Clear description
- Steps to reproduce
- Expected vs actual behavior
- Environment details
- Screenshots/logs if applicable

## Questions?

Open an issue or contact the maintainers.
