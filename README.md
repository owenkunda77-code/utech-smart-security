# U-TECH Smart Security

UTECH Smart Security Services - GPS tracking, monitoring, and recovery platform for valuable assets

## 📁 Project Structure

```
utech-smart-security/
├── backend/              # Node.js/Express API server
├── frontend/             # React web dashboard
├── mobile/               # React Native mobile app
├── docs/                 # Documentation
└── README.md
```

## 🚀 Quick Start

### Prerequisites
- Node.js 16+
- npm or yarn
- MongoDB (for database)
- React Native CLI (for mobile development)

### Installation

```bash
# Install all dependencies
npm run install-all
```

### Development

```bash
# Start backend and frontend in development mode
npm run dev
```

### Build for Production

```bash
# Build backend and frontend
npm run build
```

## 📦 Components

### Backend (`/backend`)
- Express.js server
- MongoDB integration
- JWT authentication
- Real-time GPS tracking API
- Device management
- User management
- Socket.IO for real-time updates

### Frontend (`/frontend`)
- React dashboard with Vite
- Real-time map visualization with Leaflet
- Asset tracking interface
- Admin panel
- User management
- Tailwind CSS styling

### Mobile (`/mobile`)
- React Native cross-platform app
- iOS and Android support
- Real-time GPS tracking
- Push notifications
- Offline support
- Bottom tab navigation

## 🔐 Security

- JWT-based authentication
- CORS protection
- Rate limiting
- Input validation
- Encrypted API communications
- Password hashing with bcryptjs
